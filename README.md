# Diseño de SLA Interactivo · Operaciones & Cloud IT

Este repositorio contiene una aplicación web interactiva diseñada para la visualización, comprensión y gestión de un **Acuerdo de Nivel de Servicio (SLA - Service Level Agreement)** en entornos de Operaciones y Cloud IT.

## 🚀 Características

- **Diseño Moderno y Responsivo:** Construido con Tailwind CSS y tipografía optimizada.
- **Métricas y Niveles de Servicio:** Visualización interactiva de disponibilidad, tiempos de respuesta (MTTR, MTTD) y ventanas de mantenimiento.
- **Calculadora / Simulador Interactivo:** Evaluación dinámica de impacto de incidentes y cumplimiento de SLAs.
- **Matriz de Severidad:** Clasificación de incidentes (Crítico, Alto, Medio, Bajo) y canales de escalamiento.
- **Reportes y Auditoría:** Resumen ejecutivo de cumplimiento mensual y penalizaciones/bonificaciones asociadas.

## 📂 Estructura del Proyecto

```text
├── index.html                 # Página principal (lista para GitHub Pages)
├── sla_interactivo_it.html    # Archivo fuente original del SLA interactivo
└── README.md                  # Documentación del proyecto
```

## 💻 Visualización y Ejecución

1. **Localmente:**
   - Clona este repositorio o descarga los archivos.
   - Abre `index.html` o `sla_interactivo_it.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari). No requiere servidor backend ni dependencias adicionales.

2. **GitHub Pages:**
   - Puedes activar **GitHub Pages** desde `Settings > Pages > Branch: main / (root)` para visualizar la aplicación directamente en la web.

## 🛠️ Tecnologías Utilizadas

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **JavaScript Vanilla** (lógica reactiva y cálculo de métricas)
